# Good Times

A static landing page for **Good Times**, an imaginary design and front-end development event in Melbourne.

> **Disclaimer:** This is a fictional event website, not the official website for a real conference, venue, or organization. Event details, speakers, and registration information are illustrative only.

## About the site

The page includes an event introduction, speaker profiles, a sample schedule, and a registration interface. It uses HTML, CSS, local images and fonts, and JavaScript for visual effects and smooth in-page navigation.

Some styles and scripts load from third-party CDNs, so an internet connection may be needed for the page to render as intended.

## Registration

The registration form is a visual demo only. It is not connected to a registration service or payment processor; do not submit real personal or payment information.

## Project structure

- `index.html` — page content and layout
- `css/` — stylesheets
- `js/` — page interactions and visual effects
- `images/` — image and icon assets
- `fonts/` — local font files
